# Timber Atlas - public model viewer

[Open the 33-member viewer](https://likairesearch-jpg.github.io/timber-atlas-viewer/)

[English PDF](https://likairesearch-jpg.github.io/timber-atlas-viewer/Quick_Guide_EN.pdf) | [Japanese PDF](https://likairesearch-jpg.github.io/timber-atlas-viewer/Quick_Guide_JA.pdf)

This repository contains only the static viewer, the published 33-member model, and the two PDF guides, plus publication metadata. No login, Rhino, Grasshopper, Python, or AI is required to use the hosted page. The full development repository remains private.

The draft displays precomputed analysis; it does not recalculate new cuts or arbitrary assembly sequences. It is not a structural safety certification. See the PDF for scope and installation requirements for the separate GH workflow.

The frontend files and model in this public repository are downloadable by visitors. The bundled Three.js license is retained in vendor/THREE-LICENSE.txt.
